# Search Algorithms

## 1. Project Description
Implementation of the algorithms for Binary Search and Linear Search.

## 2. Tech Stack/ Language
- Language: Java 
- IDE: Visual Studio Code

## 3. File Structure
- BinarySearch.java
- LinearSearch.java
- README.md

## 4. Features
- Binary Search 
    -searches the array using binary search to find the target. 
    -**Binary search only works with an array that is already sorted in ascending order.
-Linear search 
    -searches the array linearly to find the wanted value.

## 5. How to Run
Each algorithm contains its own test code.

## 6. Time Complexity
BinarySearch
- Time complexity: O(log n)
- Space complexity: O(1)

Linear Search
- Time complexity: O(n)
- Space complexity: O(1)
